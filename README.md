# Table of Contents
## Overview
### Description
Wanderlust is a travel website that allows users to explore and plan their trips. The website provides detailed information about various destinations, including attractions, accommodations, and travel tips.

## Installation
### Prerequisites
* Git installed on your system
* A web browser

### Steps
1. Clone the repository:
```bash
git clone https://github.com/sheikhwasimuddin/Wanderlust.git
```
2. Navigate to the project directory:
```bash
cd Wanderlust
```
3. Open index.html in your preferred web browser.

## Getting Started
### Prerequisites
* Node.js installed on your system
* A code editor

### Steps
1. Install dependencies:
```bash
npm install
```
2. Start the development server:
```bash
npm start
```
3. Open your web browser and navigate to `http://localhost:3000`

## API Documentation
### Endpoints
* `/destinations`: Returns a list of all destinations
* `/destinations/:id`: Returns a single destination by ID
* `/search`: Returns a list of destinations matching the search query

### Request Body
* `name`: The name of the destination
* `description`: A brief description of the destination
* `image`: The URL of the destination image

### Response
* `id`: The ID of the destination
* `name`: The name of the destination
* `description`: A brief description of the destination
* `image`: The URL of the destination image
